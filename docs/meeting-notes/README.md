# Meeting Notes

Raw transcripts and synthesized notes from customer/cofounder/advisor conversations.

## Convention
- File name: `YYYY-MM-DD-short-topic.md` (e.g., `2026-05-31-wine-cofounder-discussion.md`).
- Use [`_template.md`](_template.md).
- **Separate fact from suggestion:** clearly mark what was *said* vs. our own *recommendations*.
- After synthesizing, update the relevant docs (`strategy`, `competitive-research`,
  `industry-research/*`, `customer-discovery`) and log decisions in `decisions.md`.
- Use the `skills/meeting-notes` skill to do this consistently.
