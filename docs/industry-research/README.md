## How we evaluate a vertical (reuse this template)

For any new industry, capture:

1. **How money & product flow** — who buys from whom, on what terms.
2. **Core systems** — ERP, accounting, email, vendor portals, marketplaces, data feeds.
   *(What changes by industry is mostly the systems — and every system is an API.)*
3. **Manual pain** — where slow, error-prone human work lives (the automation targets).
4. **Regulatory/structural quirks** — compliance, three-tier rules, tariffs, patents, etc.
5. **ICP shape** — revenue band, employee count, tech maturity, who's the buyer.
6. **Value prop fit** — headcount replacement vs. quality-of-life; ROI story.
7. **Network / distribution** — do we have warm intros? How does land-and-expand work here?
8. **Why now / why underserved** — how antiquated is the current tooling?
