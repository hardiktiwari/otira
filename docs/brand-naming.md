## Naming criteria
1. Easy to say/spell for a non-tech owner (wine, toys) AND credible to investors.
2. AI-forward by feel; pairs with `.ai` or `get<name>.com`.
3. **No collision with any AI/ops/SaaS competitor** (this is the hard part — verify!).
4. Brandable, ownable, trademarkable.

## ✅ Formal clearance checklist (REQUIRED before committing — can't be done by web search alone)
- [ ] **Domain:** check a registrar (Namecheap/GoDaddy) for `.com`/`.ai`/`get-`/`try-` variants.
- [ ] **USPTO:** search TESS (uspto.gov) in software classes (Class 9 / Class 42).
- [ ] **Companies:** search Crunchbase/Tracxn/LinkedIn + plain Google "<name> AI".
- [ ] **Social handles:** X/LinkedIn availability.
- [ ] **Sounds-like / spelling collisions** (e.g., Mabel vs. mabl).
- [ ] Run final pick past a trademark attorney before spending on brand.
