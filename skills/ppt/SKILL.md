# Deck & Presentation Builder

Build clean, modern presentations for the company — customer pitches, investor decks, and
one-pagers.

## When to use
- A customer-facing overview (e.g., the wine "what we're thinking / what we can build / questions" deck).
- An investor deck (problem → why now → wedge → market → model → traction → team → ask).
- A one-pager translating the concept into plain English.

## Formats
- **HTML deck** (preferred for quick, self-contained, emailable artifacts; print-to-PDF via Cmd+P).
  Reference: `finance-ops-coworkers-overview.html` at the repo root.
- **PowerPoint (.pptx)** when the audience expects editable slides — see the global
  `pptx-creator` / `pptx-intuit` skills if available.

## House style
- Dark, modern, high-contrast; one accent gradient; lots of whitespace.
- **Sell outcomes, not tech.** Lead with the customer's pain and the result.
- Avoid jargon (no "MCP" in customer decks). Define ERP/context-layer in plain words.
- 3–10 slides max; one idea per slide; scannable.

## Reusable narrative beats
1. What we're thinking (the concept) — generic headline, then tailor to the prospect.
2. What we can build for *you* — lead with ONE wedge workflow as a visual flow.
3. Questions for you / next step — discovery + a fixed-scope pilot.

## Checklist
- [ ] Headline is outcome-focused and not vertical-locked (reusable across prospects).
- [ ] One clear wedge use case shown concretely.
- [ ] A "why us vs. <closest competitor>" line where relevant.
- [ ] A single, low-commitment call to action.
- [ ] Print-to-PDF friendly.
